# Baron Launcher

A premium Minecraft Java Edition launcher project.

## Current milestone

**Phase 1 — UI foundation**

- React + TypeScript + Vite
- Black / titanium / red visual system
- Compact sidebar and large dashboard
- Home, Versions, Mods, Modpacks, Profiles, Customization and Settings screens
- Responsive layout for desktop and smaller windows

The current build is a UI prototype. Minecraft installation, Microsoft authentication, mod downloads, backups and auto-updates are not implemented yet.

## Development

```bash
npm install
npm run dev
```

## Production UI build

```bash
npm run build
npm run preview
```

## Planned desktop packaging

Electron integration will be added in a later milestone, after the UI is reviewed.
